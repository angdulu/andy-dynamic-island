# Andy 2.2.11

This update improves local dictation reliability and reduces the resources used by Dictation-Only Mode.

- Updated the bundled whisper.cpp runtime to v1.9.5 with Metal acceleration and active Silero speech detection.
- Added Whisper Turbo Q5, a 574 MB multilingual model available in Settings > Dictation. Existing model selections are preserved.
- Fixed cold startup so recording and transcription share the same model-readiness check. Local Whisper servers now use an available port and shut down without blocking the app.
- Added retry and discard controls for the most recent failed recording. Recovery expires after 24 hours; expired files are removed while Andy is running or at the next launch.
- Added Copy Last Transcript and preserved text when Accessibility permission is missing or the active app changes before insertion.
- Added Automatic, English, and Korean transcription language choices. Automatic remains the default.
- Added configurable model unloading after inactivity: 5, 10, or 30 minutes, or always keep loaded. The default is 10 minutes. Models reload automatically when dictation starts and remain loaded during recording or transcription.
- Disabled unnecessary Bluetooth polling, Downloads monitoring, extension services, weather warmup, and memory polling in Dictation-Only Mode.
- Reduced the app bundle by removing duplicate resources and libraries, and removed unused legacy transcription code.
- Preserved the original transcript if optional AI cleanup returns empty or truncated output.

## Compatibility

Apple Silicon Mac, macOS 14.6 or later. Dictation remains local. Transcription model files are downloaded separately from the app.

## Validation

Release build and code-signature verification passed. Focused tests cover shared startup, switching models, cancellation, failures, timeouts, and recording recovery. Packaged-runtime checks cover English speech, synthesized Korean speech, a short Korean utterance with an explicit language hint, and silence detection.
